# Календар івенту 31.10

Сайт для команди Bad&Beezy × R22MIE: хронологічна пряма проєкту, тиждень і день, дані з дошки Trello «31.10». Вхід за спільним паролем.

## Як влаштовано

- `index.html` — сторінка-календар.
- `api/board.js` — функція Vercel, яка читає дошку Trello від імені власника ключа й віддає картки сторінці. Ключ і токен Trello лишаються на сервері, у браузер не потрапляють.

## Змінні середовища у Vercel

| Назва | Що це |
|---|---|
| `TRELLO_KEY` | API-ключ Trello (trello.com/power-ups/admin) |
| `TRELLO_TOKEN` | Токен Trello для цього ключа |
| `SITE_PASSWORD` | Пароль, який вводять на сайті |
| `TRELLO_BOARD` | Необов'язково. ID або shortLink дошки, за замовчуванням `kSYANrdB` |

Після зміни змінних треба зробити Redeploy, щоб вони підхопилися.

## Як оновлюється

Сторінка звертається до `/api/board` щохвилини, поки відкрита. Статус береться з Trello: виконана картка — «Готово», минув строк — «Прострочено», інакше — рядок «Статус:» в описі картки. Відповідальний — назва колонки до дужок.
